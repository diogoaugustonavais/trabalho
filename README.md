# trabalho

 O GITHUB é uma plataforma baseada em nuvem que é possivel armazenar, compartilhar e trabalhar com outras pessoas para escrever códigos.
 Com o GITHUB é possiver demonstrar e compartilhar o seu trabalho para outras pessoas, acompanhas e gerenciar alterações nos codigos ao longo do tempo, permitir que outras pessoas revisem os seus codigos e deem sugestões para melhorá-lo e Colaborar em projetos compartilhados sem se preocupar que suas alterações afetarão o trabalho de seus colaboradores antes que voce esteja pronto para integrá-los.
 Trabalho colaborativo é uma das caracteristicas fundamentais do GitHub, isso é possivel graças ao software de codigo aberto GIT, que serviu como base para criação do GitHub.

 O GIT é o sistema de controle de versão que acompanha as alterações nos arquivos de forma inteligente. Ele particulamente é util quando você e um grupo de pessoas fazem alterações nos mesmos arquivos ao mesmo tempo.
 Com o Git é possivel que você crie uma ramificação a partir da copia principal dos arquivos em que você (e seus colaboradores) estão trabalhando, fazer edições nos arquivos de forma independente e segura em sua própria ramificação pessoal, Permitir que o Git mescle de forma inteligente suas alterações específicas na cópia main dos arquivos para que suas alterações não afetem as atualizações de outras pessoas, e deixar o Git rastrear suas alterações e as de outras pessoas para que todos permaneçam trabalhando na versão mais atualizada do projeto.

comandos básicos do Git
 git add
O git add adiciona conteúdo do diretório de trabalho à área de preparação (ou "índice") para o próximo commit.
 git status
O git status mostrará os diferentes estados dos arquivos no seu diretório de trabalho e na área de preparação.
 git diff
O git diff é usado quando você deseja ver as diferenças entre quaisquer duas árvores.
 git difftool
O git difftool simplesmente inicia uma ferramenta externa para mostrar a diferença entre duas árvores, caso você queira usar algo diferente do git diff integrado.
 git commit
O git commit pega todo o conteúdo dos arquivos que foram preparados com o git add e registra um novo snapshot permanente no banco de dados, movendo em seguida o ponteiro do branch atual para esse snapshot.
 git reset
O git reset é usado principalmente para desfazer ações, como você pode deduzir pelo verbo.
 git rm
O git rm é usado para remover arquivos da área de preparação e do diretório de trabalho do Git.
 git mv
O git mv é um comando simples e prático para mover um arquivo e, em seguida, executar comandos tanto git add no arquivo novo quanto git rm no arquivo antigo.
 git clean
O git clean é usado para remover arquivos indesejados do seu diretório de trabalho.
