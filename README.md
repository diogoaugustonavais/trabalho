# trabalho

O GITHUB é uma plataforma baseada em nuvem que é possivel armazenar, compartilhar e trabalhar com outras pessoas para escrever códigos.
Com o GITHUB é possiver demonstrar e compartilhar o seu trabalho para outras pessoas, acompanhas e gerenciar alterações nos codigos ao longo do tempo, permitir que outras pessoas revisem os seus codigos e deem sugestões para melhorá-lo e Colaborar em projetos compartilhados sem se preocupar que suas alterações afetarão o trabalho de seus colaboradores antes que voce esteja pronto para integrá-los.
Trabalho colaborativo é uma das caracteristicas fundamentais do GitHub, isso é possivel graças ao software de codigo aberto GIT, que serviu como base para criação do GitHub.

O GIT é o sistema de controle de versão que acompanha as alterações nos arquivos de forma inteligente. Ele particulamente é util quando você e um grupo de pessoas fazem alterações nos mesmos arquivos ao mesmo tempo.
